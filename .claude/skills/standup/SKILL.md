# Standup report

Формирует детальный отчёт о том, что было сделано вчера, на основе
git-истории — для использования на стендапе.

## Практика

1. **Определить границы "вчера"** через `date` (учитывай, что окружение —
   macOS/BSD `date`, а не GNU):

   ```bash
   date -v-1d +%Y-%m-%d                              # вчерашняя дата
   date -v-1d -v0H -v0M -v0S +"%Y-%m-%d %H:%M:%S"     # начало вчерашнего дня
   date -v0H -v0M -v0S +"%Y-%m-%d %H:%M:%S"           # начало сегодняшнего дня (конец диапазона)
   ```

2. **Определить автора** — текущего git-пользователя, чьи коммиты нужны:

   ```bash
   git config user.name
   git config user.email
   ```

3. **Собрать коммиты за вчера по всем веткам**, отфильтровав по автору и
   диапазону дат:

   ```bash
   git log --all --author="<имя или email>" \
     --since="<начало вчера>" --until="<начало сегодня>" \
     --pretty=format:"%H|%ad|%s" --date=format:"%H:%M"
   ```

4. **Для каждого найденного коммита** получить детали — полное сообщение
   (включая тело) и статистику изменённых файлов:

   ```bash
   git show --stat --pretty=format:"%B" <hash>
   ```

   При необходимости — на какой ветке коммит был сделан:

   ```bash
   git branch --all --contains <hash>
   ```

5. **Собрать отчёт** в следующем виде:

   ```
   # Стендап-отчёт — <вчерашняя дата>

   ## Сделано (N коммитов)

   - **<HH:MM> <scope>: <summary>** (`<short-hash>`)
     <развёрнутое описание из тела коммита, если оно есть — своими
     словами, что именно изменилось и зачем>
     Файлы: <N файлов, +ins/-del>

   - ...

   ## Итог
   <2-4 предложения, обобщающих день: над чем в целом шла работа,
   какие фичи/фиксы продвинулись>
   ```

   Порядок коммитов — хронологический (от раннего к позднему). Описание
   должно быть содержательным для стендапа: не просто пересказ summary
   коммита, а что это значит для проекта (например, "добавлен endpoint
   X, чтобы фронт мог получать Y" — а не просто повтор заголовка).

6. **Если за вчера коммитов не найдено** — сообщить об этом явно и не
   выдумывать работу: "вчера коммитов не было — если была
   некоммитящаяся работа (ревью, дизайн, встречи), добавь её вручную".
